Repositório dedicado às resoluções dos *Problem Sets* (conjunto de problemas) do curso **CC50** (CS50x), oferecido pela Fundação Estudar em parceria com a Universidade de Harvard.

Este curso exige uma forte carga de raciocínio lógico e resolução de problemas, abordando desde os fundamentos da computação e gestão de memória até ao desenvolvimento web.

## 🛠️ Tecnologias e Conceitos Abordados
* **Baixo Nível:** C (Ponteiros, Gestão Manual de Memória, Alocação Dinâmica)
* **Estruturas de Dados:** Arrays, Listas Ligadas, Tabelas Hash, Árvores
* **Alto Nível & Dados:** Python, SQL (SQLite)
* **Desenvolvimento Web:** Flask, HTML, CSS
* **Fundamentos:** Algoritmos de Ordenação e Pesquisa, Complexidade Assintótica (Big O)

## 📂 Estrutura do Repositório

Abaixo estão as soluções organizadas pelos módulos concluídos:

* **[Module 1](./Módulo%201): C** 
  * Lógica de loops aninhados, algoritmos gulosos e operações matemáticas (ex: Mario, Cash, Population).
* **[Module 2](./Módulo%202): Arrays**
  * Manipulação de strings e criptografia básica (ex: Readability, Caesar).
* **[Module 3](./Módulo%203): Algoritmos**
  * Algoritmos de ordenação e sistemas de votação (ex: Plurality, Runoff).
* **[Module 4](./Módulo%204): Memória**
  * Manipulação de pixels de imagens e recuperação de ficheiros usando ponteiros (ex: Filter, Recover).
* **[Module 5](./Módulo%205): Estruturas de Dados**
  * Verificador ortográfico de alta performance construído com uma Tabela Hash e gestão manual de memória (Speller).
* **[Module 6](./Módulo%206): Python**
  * Transição de conceitos de C para Python e identificação de perfis de ADN (ex: DNA).
* **[Module 7](./Módulo%207): SQL**
  * Resolução de mistérios através de consultas a bases de dados relacionais (ex: Fiftyville).
* **[Module 9](./Módulo%209): Flask**
  * Aplicação web consumindo APIs externas e gerindo bases de dados (ex: Finance).
